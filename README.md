### RenderShot — API de screenshot e PDF

Produto próprio, publicado e monetizado: transforma qualquer URL ou HTML em PNG/JPEG/WebP ou PDF. Full-page, presets de dispositivo, dark mode, bloqueio de banner de cookie, clipping por seletor.

- [`rendershot-action`](https://github.com/edubraqd/rendershot-action) — GitHub Action oficial, captura dentro do workflow sem Chromium local
- [`rendershot-examples`](https://github.com/edubraqd/rendershot-examples) — exemplos em cURL, Node, Python, PHP, Postman e GitHub Actions
- Site: [rendershot.dev](https://rendershot.dev) · Docs: [api.rendershot.dev/docs](https://api.rendershot.dev/docs) · [RapidAPI](https://rapidapi.com/eduardoalcantarasp/api/screenshot-e-pdf-render)
